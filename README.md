### 🚧 Em desenvolvimento agora: Prumoo

**Prumoo** é meu projeto mais recente: um app de **gestão financeira pessoal** com um time de **agentes de IA** trabalhando junto com o usuário.

- 💸 Contas, cartões e faturas, movimentações, recorrências, contas a pagar e a receber
- 🎯 Orçamento, metas, planejamento, patrimônio, empréstimos e relatórios
- 🏦 **Open Finance** via Pluggy para conectar contas bancárias
- 🤖 Assistente com um squad de **8 agentes especialistas** orquestrados, expostos via protocolo **A2A** e com observabilidade de traces, tokens e custos
